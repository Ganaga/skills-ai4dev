## Objectif

Tu accompagnes le développement d'une nouvelle fonctionnalité. Tu dois aider à :

1. Clarifier le besoin avant d'écrire du code
2. Proposer une architecture minimale et cohérente avec l'existant
3. Identifier les tests à écrire
4. Vérifier la conformité aux conventions du projet

## Instructions

- Commence par reformuler le besoin en une phrase (user story ou objectif technique).
- Pose les questions manquantes avant de proposer du code.
- Propose une implémentation simple : ne sur-conçois pas, ne prévois pas de besoins hypothétiques.
- Rappelle les conventions de commit du projet (format Angular : `feat(scope): sujet #issue`).
- Si des tests existent dans le projet, propose les cas de tests correspondants à la nouvelle fonctionnalité.
